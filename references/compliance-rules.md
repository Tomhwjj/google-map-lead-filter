# 合规边界 + 限速规则

> 一句话：只抓**公开的、商业的、能验证的**信息；不碰隐私、不绕墙、不造假、不超频。

## 允许

- 抓取 Google Maps 公开搜索结果（商家公开信息：名称/电话/官网/评分/地址）
- 抓取公司**官网**的公开页面（首页 / contact / about / imprint）
- 查询公开商业目录、展会名录、企业注册信息
- 用 WebSearch 搜公司公开的 LinkedIn 主页

## 不允许

- 绕验证码 / 登录墙 / 付费墙
- 抓取个人隐私数据（私人社交主页、员工私人信息）
- 抓取社交平台的成员/粉丝/评论列表
- 编造不存在的公司、邮箱、联系人

## 限速（防止触发 Google Maps 反爬）

- 滚动加载之间延迟 **2-3 秒**
- 每个搜索词之间延迟
- 单次搜索抓取上限 **50 条**
- 不并发抓取

## 禁止行为（用户规格，铁律）

1. 不得自动发送邮件
2. 不得编造不存在的公司信息
3. 不得将 C 级线索标记为 A 级
4. 不得超过 Google Maps 的抓取频率限制

## 若用户要求违规抓取

回复：

> 这个来源涉及平台限制或个人资料抓取，我不能直接用爬虫抓取。可以改为查询企业官网、公开商业目录、展会名录、B2B 平台、政府注册信息。

然后继续用合规方式。
